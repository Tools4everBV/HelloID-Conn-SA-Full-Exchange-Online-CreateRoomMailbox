# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com),
and this project adheres to [Semantic Versioning](https://semver.org).

## [3.0.0] - 2026-06-08

### Changed
- Performed a major delegated form update covering both implementation resources and documentation.
- Reworked delegated form resources and scripts in the repository, including datasource/task resource structure and all-in-one setup alignment.
- Introduced Microsoft Entra ID based validation and domain lookup datasource resources for alias, display name, and email uniqueness checks.
- Rewritten the README with prerequisites, permissions, connection settings, and technical behavior with the current script implementation.

## [2.0.0] - 2023-07-13

- Updated connector to version 2.0.0.
